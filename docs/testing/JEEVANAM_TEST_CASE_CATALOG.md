# Jeevanam Healthcare Test Case Catalog

This catalog is automation-oriented and derived from the current repository implementation. The scenarios below are phrased so that each test case covers both the happy path and the main negative variant when appropriate.

Legend:

- **Priority**: `P0` blocker, `P1` major workflow, `P2` secondary regression, `P3` cosmetic / low risk
- **Automation**: `AUTOMATE_NOW`, `AUTOMATE_LATER`, `MANUAL_ONLY`, `NOT_RECOMMENDED`

## Coverage notes

- Many scenarios have both backend and frontend tests; the existing tests are mostly source-backed regression tests, route tests, or backend service/controller tests.
- The catalog intentionally separates publication-boundary scenarios from general discover browsing.
- Hospital, clinic, and doctor publication flows are represented through the same provider-workflow family because the implementation shares the same Discover/public-profile stack.
